## 5. 정직성 규칙 (check_site.py)

1. 상용 게임명 금지(원문 페이지 제외).
2. 평가 대시보드 결과 셀은 `NOT RUN` 뿐. 게이트 수치는 "초기안".
3. 모든 `mock-frame` 에 `MOCK` 배지.
4. `Horn remaining` 부재.
5. 원시 `href="/…"` 금지, 내부 링크 전부 `_site` 에서 해소.
6. 구현 현황 절에 v4 기준 경고.
